Every answer it produces — requirements specs, API designs, ER diagrams, SQL queries, and architecture plans — is grounded in your **live PostgreSQL database**, your **codebase dependency graph**, and your **indexed documentation**. Choose the runtime that fits your workflow: drop it in as a Claude Code or Codex plugin, or run the Chat GUI for a full browser-based experience.

## How It Works

SA Agent runs a structured, phase-by-phase workflow. Each phase produces one approved artifact before the next begins — keeping the LLM focused and the human in control.

<Steps>
  <Step title="Discuss">
    The **System Analyst** reads your request, inspects the live schema, and returns a gap-free field mapping. You approve before anything is planned.
  </Step>
  <Step title="Plan">
    The **Solution Architect** turns the approved spec into an architecture design with Mermaid diagrams and an execute checklist. You approve before any code is written.
  </Step>
  <Step title="Execute & Test">
    The **Coder** implements the plan. The **Test Engineer** quizzes the implementation against the original spec. Both require your sign-off.
  </Step>
  <Step title="Review & Ship">
    The **Reviewer** checks the diff against the plan. You commit and open the PR — SA Agent never ships on your behalf.
  </Step>
</Steps>

## Key Features

<CardGroup cols={3}>
  <Card title="Live Schema Grounding" icon="database">
    Column types, foreign key graphs, and table relationships are always read from the live database — never from stale snapshots.
  </Card>
  <Card title="System Model" icon="diagram-project">
    A typed dependency graph of your repo answers "what connects to what" and "why is this like this" without hallucinating.
  </Card>
  <Card title="Decision Records" icon="book-open">
    Engineering reasoning is captured as markdown records linked into the code graph, so future changes know what constraints exist.
  </Card>
  <Card title="Claude Code & Codex" icon="puzzle-piece">
    Install as a plugin in your product repo. SA Agent supplies the tools; your preferred LLM runtime supplies the intelligence.
  </Card>
  <Card title="PVT Prep Track" icon="flask">
    Generate numbered, owner-tagged SQL scripts for Production Verification Tests — staged before the window, ready for SRE.
  </Card>
  <Card title="Jira Integration" icon="ticket">
    Pull ticket and user-story context on demand. SA Agent only calls Jira when you explicitly ask for a ticket.
  </Card>
